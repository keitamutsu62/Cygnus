// 01 — PHILOSOPHY

私たちが大切にすること

注目ではなく、
信頼を積み上げる。

技術は消費されるべきではありません。一つひとつの施術、一人ひとりとの対話、一日一日の鍛錬。それらは静かに積み重なり、美容師個人のキャリアとして残されるべきものです。

けれど現実には、サロンに蓄積されたデータは転職とともに消え、SNSの数字は流れていき、技術への投資は誰のものとも分からないまま霧散します。

Cygnusは、その流れを変えるためのインフラです。

// 02 — INDUSTRY

美容業界が抱える課題

飽和市場、断絶した情報、消えていく実績。
業界の構造そのものが、技術者のキャリアを支えきれていない。

26万件
美容室数
店舗数だけが増え、業務効率化は進んでいない。利用するツールが分断され、正確なデータ管理と分析が困難。
60% 超
3年離職率
業界の構造的問題。サロンに蓄積された実績は、転職とともに消えていく。
約15%
フリーランス美容師
サロンに所属しない働き方が増加。約8万人の美容師が個人で活動し、組織から個人への大きな流れが進んでいる。
// CORE PROBLEMS
01
ツールが分断されている
POS、在庫、予約、カルテ。それぞれ別々のシステムに散らばり、データが繋がらない。経営判断が感覚に頼らざるを得ない構造。
02
美容師個人にデータが残らない
売上、指名、技術履歴はサロンに蓄積される。けれど転職すれば、それは消える。キャリアが可視化されないまま、次のステージに進めない。
03
個人で動く美容師を支える基盤がない
フリーランス・面貸し・業務委託など、サロンに所属しない働き方が増えている。しかし予約・顧客管理・実績の蓄積を個人で行う仕組みは整っておらず、それぞれが孤立した状態で運営している。

// 04 — PRODUCTS

7つのプロダクト

それぞれが独立し、それぞれが繋がる。
すべては美容師個人を中心に設計されています。

ID
Cygnus ID
Identity Layer / 基盤
美容師個人に紐づく統合ID。すべてのプロダクトの結節点となり、データを個人のものとして守ります。
LOOP
Cygnus LOOP
Operations Layer / サロン経営
在庫・売上・スタッフ管理を統合したサロン向けSaaS。技術に集中できる環境を整えます。
STUDIO
Cygnus STUDIO
Craft Archive Layer / ポートフォリオ
個人の作品・実績・学習履歴を永続的に蓄積。技術を作品として残します。
RESERVE
Cygnus RESERVE
Relationship Layer / 個人予約
顧客から美容師個人への直接予約システム。予約と関係性の入口に。
AI
Cygnus AI
Intelligence Layer / 課題発掘
売上・指名データから得意領域とブランディングを分析。技術者の思考を支援します。
ACADEMY
Cygnus ACADEMY
Learning Layer / 技術研鑽
課題に応じた技術研修・学習プラットフォーム。学びと成長をサポートします。
ORBIT
Cygnus Orbit
Matching Layer / マッチング
サロンと美容師の双方向データドリブン採用。実績データを基に、出会うべき相手と出会う場所を提供します。

// 06 — FOUNDER

創業者からのメッセージ

美容師の友人と話す中で気づいた、業界の構造的な課題。

美容師個人を中心に据えたエコシステム「Cygnus」を立ち上げ、現場と共に未来を作っています。

Cygnusは、現役美容師とWEBマーケターという全く違う畑出身の二人で立ち上げているプロダクトです。

大企業の論理ではなく、現場の声を起点に。事業計画よりも、目の前のサロン経営者と美容師の課題を解くことから始めました。

サロン経営SaaSから個人マッチングまで、業界全体をつなぐインフラを開発しています。
